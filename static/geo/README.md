# Geometrías territoriales de Chile

La visualización territorial utiliza `chile-regiones.geojson` y `chile-comunas.geojson`, obtenidos del repositorio público [fcortes/Chile-GeoJSON](https://github.com/fcortes/Chile-GeoJSON), que documenta como referencia los mapas vectoriales de la Biblioteca del Congreso Nacional de Chile.

Fuente de los archivos:

- https://raw.githubusercontent.com/fcortes/Chile-GeoJSON/master/regiones_edit.geojson
- https://raw.githubusercontent.com/fcortes/Chile-GeoJSON/master/comunas.geojson

Los archivos se sirven localmente para evitar consultas de geometrías en tiempo de ejecución. La aplicación no geocodifica ni modifica las geometrías. Antes de redistribuir estos archivos fuera del proyecto debe verificarse la licencia vigente del repositorio fuente y de sus referencias cartográficas.
